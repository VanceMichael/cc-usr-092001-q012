# 领域约定

畜禽表型标准接入网关围绕表型采集、设备校准与个体谱系保存可核对的业务记录。外部主体使用不含真实身份信息的稳定引用编号，时间采用带偏移量的 ISO 8601 字符串，材料只保存受控引用和 `sha256` 摘要。

## 标准版本

物种、性状定义、采集流程（日龄时间窗口）与数据格式都登记在某个标准版本下。标准版本经历 `draft → effective → retired`：草案期可登记规则，生效后规则冻结，升级只能登记新版本。接收采集记录时按 `occurred_at` 解析当时生效的版本并绑定到记录上；标准升级只影响生效后的采集，已保存数据永不重释。

## 接收与校验

批量上传（含离线设备补传）按发生时刻的标准版本校验：单位、精度（按原始读数原文的小数位数）、取值范围、日龄时间窗口、设备适用范围（物种与性状）以及覆盖采集时刻的校准证书。同一（设备序号, 来源序号）只接受一次，重复补传去重；被拒记录同样保存并附拒收原因，修正后可用同一来源序号重新上报。

原始读数、修订值、质量标记分别保存：原始读数一经保存不可改写，修订只追加修订记录，当前值取最新修订值。

## 谱系

个体合并或标识纠错只追加合并映射，不删除历史。观测记录同时保存上报时的原始标识与解析后的规范编号；谱系查询沿合并链解析，亲缘链不中断。

## 数据切片与溯源

研究机构的数据切片申请经批准后才能取数；未获主体信息授权时，输出中的个体编号替换为申请维度的假名，谱系信息不输出，用途范围之外的性状不出现。跨机构质量反馈与拒收原因可按观测、按机构查询。育种分析数据集登记其来源观测，溯源报告给出每条来源的原始读数、测定设备、校准证书与标准版本。
